Street-Block GNN Prediction

A graph neural network that predicts the urbanity of a street block directly from its polygon geometry, extending the street-block machine-learning study with end-to-end geometric learning.

Abstract

This project extends the Street-Block Machine Learning study under the same premise: how much urban structure can be inferred solely from street-block geometry, independent of socioeconomic or land-use data. Using street-block data from the United States Census Bureau, the study focuses on the top ten U.S. metropolitan areas by GDP. The ground-truth label is the UR20 attribute, framing the task as a binary classification (urban vs. rural). Where the previous approach relied on four handcrafted geometric features (area, isoperimetric quotient, rectangularity, and solidity), this project asks a more fundamental question: can a model learn urbanity directly from geometry itself? Street blocks are represented as graphs derived from polygon topology, and a Graph Neural Network is trained to classify urban versus rural blocks from purely learned geometric representations.

Workflow

QGIS: shapefiles loaded, clipped to a 30-mile radius per city, base geometric attributes calculated, and processed layers exported.
PostgreSQL / PostGIS: city-wise processed geometries and UR20 labels stored, enabling consistent querying and reproducible splits.
Python + PyTorch Geometric: ten cities loaded, blocks converted into graph representations, a GNN trained on nine cities with Houston as a fixed validation set, and generalization tested on an unseen city, Philadelphia.

Street block to graph

Street blocks can be modeled either as rasterized images or as graphs. An image representation forces a grid-based approximation and often loses precise corner-to-corner structure, while a graph preserves the true topology of the polygon, capturing the explicit relationships between corners (nodes) and edges (connections).
Each street block is converted into a planar graph where polygon vertices become nodes and consecutive boundary segments become edges. Node features are stored in an N×5 matrix, where each vertex carries five attributes: (x, y) coordinates, turning angle at the vertex, and the lengths of the two adjacent boundary edges. The conversion pipeline standardizes vertex ordering, removes duplicate points, computes angles and edge lengths, builds the edge index from sequential connectivity (including wrap-around), and outputs a graph object for training.

Neural network iterations

The model is a GNN that learns hierarchical geometric representations of street-block graphs. In Iteration 1, node embeddings are projected through a graph convolution into an N×64 latent space, followed by a graph-level readout and an MLP (64 → 128 → 256 → 1) for binary classification, prioritizing rapid convergence and controlled capacity. In Iteration 2, capacity is increased: convolution layers output N×128 embeddings, and the MLP is restructured as 128 → 128 → 128 → 128 → 1, emphasizing deeper but uniform transformations. Both are trained end-to-end with global pooling, isolating the impact of the architectural change.

Treating imbalanced data

The dataset is severely imbalanced: urban blocks make up roughly 98% of all street blocks by count, while rural blocks are a small minority. By total area, though, the imbalance is milder, since rural blocks are much larger, so block count alone is a misleading indicator of spatial dominance.
Synthetic oversampling such as SMOTE was intentionally avoided: street-block geometry is highly sensitive to small perturbations, and synthetic samples risk topologically invalid or physically implausible shapes that corrupt the learning signal. Instead, imbalance is addressed with area-based loss weighting, so misclassification penalties scale with each block's spatial footprint rather than raw counts. This aligns the objective with spatial reality, reduces bias toward the majority urban class, and preserves the original geometries.

Final result and implication

The deep-learning approach reaches 94.55% accuracy, only marginally above the 93.74% of the earlier logistic-regression model. The confusion matrices show where the difference lies: logistic regression strongly favors the majority class, giving high urban recall but weak rural recognition, with many rural blocks misclassified as urban.

The GNN shows a more balanced error distribution, improving precision and recall for the minority rural class and yielding a cleaner separation, evidence that it extracts subtle geometric signals that distinguish large rural blocks from dense urban fabric. But the gains are bounded: across 50 epochs the loss and error plateau after roughly 20, with little further improvement. Street-block geometry alone has a limited explanatory ceiling for urban classification; the GNN refines results within that limit rather than overcoming it, and richer contextual or semantic data would be needed for larger gains.
